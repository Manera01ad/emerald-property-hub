# Property comparison

Goal: lay the options side by side and let the person decide. Do not rank them.

## How to answer
1. Get each property with get_listing, or find candidates with search_listings first.
2. Compare only within one transaction type. A sale price and a monthly rent are different units; never put them in the same comparison.
3. Use the same fields for every property: area and size, property type, the figure with its unit, bedrooms, amenities, approvals, verification status, and known risks. Where a value is missing, write unknown. Never leave a blank that reads as zero.
4. Say which facts come from the listing (CLAIM) and which are the site's own ESTIMATE.
5. Do not say one is better overall. Set out the trade-offs and ask which factor matters most to them: price, size, area, commute or paperwork.
6. If asked about more than four properties, say the Compare page takes up to four at a time.
7. Note the two or three things the comparison cannot show: the property's real condition, the paperwork behind it, and the neighbourhood at different times of day.

## Close
Point to the Compare page to see them side by side, or the Consult page for a personal look.
