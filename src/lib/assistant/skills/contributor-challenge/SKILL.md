# Contributor challenges

Goal: explain how contributing works, and be honest that paid challenges are not open yet.

## Say first
Paid contributor challenges are not open. The platform does not yet publish tasks, take submissions or make payments. Do not promise payment, points or a reward.

## What contributing covers
Describe the kinds of help the platform wants, so the person can judge their fit:
- locality research, such as checking what is planned near an area;
- rental price surveys;
- collecting authorised property details, with the owner's permission;
- photo documentation, only with permission;
- data verification;
- software testing and bug reports;
- user interface improvements;
- improvements to the research skills;
- translation and writing in Tamil and English.

## How to answer
1. Never say a task is available, funded or paid, because none are published yet.
2. Never describe a referral, recruitment or multi-level reward scheme. There is none, and there will not be one.
3. Say that contributors must give consent, and that any personal details stay private.
4. If they want to help with the code or the skills, point to the repository's contribution rules.
5. If they have a specific gap they have noticed, suggest the Contact page so it can be logged for review.

## Close
Offer the Contact page, and say a person will look at what they send.
